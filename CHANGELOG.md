# Changelog

## V0.1, 2026-11-05

First validated public release, live at https://911corp.github.io/garys-weird-web/.

- Discovery: one [REDACTED] button draws a real website blind, then a discovery report (field, contents, Gary's take, weirdness, address, checks) before opening it. Today's signal follows the UTC day. Frequency chips filter by category.
- Catalogue: 779 sites, 684 in RANDOM, every description validated. Sites that are down are paused or withdrawn, moved addresses are fixed.
- Favorites, Archive (Discovered, Favorites, and a Full archive behind a playful admin password), Passport with level, achievements, export and reset.
- Terminal (`/`): blackbox, preview, chaos, rabbit, login, report, share, version and more.
- Sharing: native share sheet, X, Bluesky, Reddit, WhatsApp, copy link. Links stay blind (`#s=GWW-xxxx`).
- Report a site that is down, kept on the device.
- Privacy: no server, no account, no analytics, no third-party script, no remote image. Everything stays in localStorage.
- Weekly report-only link check on GitHub Actions.
- Tests: 174 end-to-end and accessibility checks, editorial integrity tests, release gate.
- Favicon: G: in Geist Mono, the site font (ICO, PNG, Apple touch icon), web manifest and a 1200x630 share preview image for X, Bluesky, Reddit, WhatsApp and messaging apps. All served by the site itself.
